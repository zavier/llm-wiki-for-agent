# Senko Rašić

克罗地亚 Zagreb 的资深软件开发者(~25 年);技术博客 senko.net/blog;LLM 时代职业话语的 **craft 辩护派**代表——反"code is easy"话语,主张理解/判断/共情/品味不外包给 AI。

## 关键信息

- 身份:About 页自述"live in Zagreb, Croatia; worked as a software developer for around 25 years"(2026-08 核实);桌面 Linux 用户(Debian/GNOME/Wayland,超宽屏 32:9)
- 2026-08-08 发表 [[2026-08-08-code-was-never-the-hard-part|"Code was never the hard part" is an insult to all programmers]]:反驳"编码容易/软件从来不是难点"与"只有搞清楚做什么才难"两话语;"两者都难都重要"(¿Por qué no los dos?)
- 2025-09-15 发表 [[2025-09-15-your-code-is-your-responsibility|Your code is your responsibility, even if AI wrote it]]:责任观原发(第 51 源)——提交 PR = 声明完全理解 + 合法权利;隐藏 AI/外包使用 = 操守违规;原型/内部工具可 vibe;"AI 写的" = 狗吃作业
- 立场:
  - **craft 辩护**:编码 = 需技能/耐心/细节/经验/智慧的技艺,AI 时代仍相关;"code is easy"与"code is art 不可自动化"都是 cope
  - **判断与品味不外包**:"AI 是 fancy autocomplete;我要控制思考、引导、判断它的努力;AI 给选项,我挑选"(2026 开放权重模型试玩文中重申:理解/判断/共情/品味四样不外包)
  - 对 AI 务实:不跳 LLM 班车、不誓死抵抗,接受行业级变化,好奇+批判
- 关注面:开放权重模型(Kimi K3/Qwen 3.8 Max 试玩评论,2026)、LLM 职业话语、桌面 Linux
- 时间线:责任观(2025-09-15)早于 craft 辩护文(2026-08-08)近一年,后者将其作为底线引用("don't abdicate your responsibility")
